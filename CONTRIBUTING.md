# Contributing

Thanks for helping improve the project.

Before opening a pull request:

1. Run `npm test`.
2. Test the adapter you changed in the relevant client.
3. Keep client-specific behavior in the appropriate adapter.
4. Update the README when installation or supported-client behavior changes.
5. Do not include API keys, tokens, private files, personal absolute paths, or unrelated generated files.
6. Do not add an automatic installer that overwrites existing configuration without an explicit backup and confirmation.

The project is intentionally small. A focused change with a clear verification result is more useful than a broad refactor.
